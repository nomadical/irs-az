Leylim içün leylîm içün ben bini mecnûn ideyim
Gözlerümün kan yaşını yolma ceyhûn ideyim

Geh sâdî gözleriyiçün ben gözümi ayn ideyim
Gâhî elif boyıyiçün kaddümi çün nün ideyim

Hammârî gözleriyiçün gönüli yürek kıluban
Göz şîşesin ayağ idüp yaşumı mey-gûn ideyim

Çün saldı çengine cânı ışkı odı micmerine
Ben dahi ûd tek yanmağı âlemde kânûn ideyim

Evvel kadem yüregümi toldurdı gözüm kan ile
Ol kan içün şimdi gözi kan yaş ile hûn ideyim
