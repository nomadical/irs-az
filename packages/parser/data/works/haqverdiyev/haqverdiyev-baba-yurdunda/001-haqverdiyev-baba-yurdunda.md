mülkədar, otuz beş yaşında

**Ehsanxan** – qoca mülkədar, Cahangir ağanın mülk qonşusu

**Namaz** – Cahangir ağanın darğası

**Gülnisə** } kənd qızları

**Balaqız** } kənd qızları

**Həsən** – Gülnisənin atası

**Tubu** – Həsənin arvadı

**Sadıq** } kəndli

**Həzrətqulu** } kəndli

**Şahmarbəy** - pristav

Aşıq Cəfər – saz aşığı

Iskəndərzadə – dairə icraiyyə komitəsi sədri
