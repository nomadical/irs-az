# Amandı

Özün yaxşı-pis qapılar açarsan,
Bir ox atıb könlüm evin yıxarsan,
Qanrılıb qanrılıb nagah baxarsan,
Qan eylər gözlərin, ay qız, amandı

Yerində kəklik kimi yırğanır,
Qayın anası onu məndən qorğanır,
Hər tilinə beş yüz tümən bağlanır,
Qan eylər gözlərin, ay qız, amandı

Özün çox gözəlsən, yanağın lala,
Canıma salıbsan qəfildən bala,
Yazıq Mərdan oğlu yanında qala,
Qan eylər gözlərin, ay qız, amandı
