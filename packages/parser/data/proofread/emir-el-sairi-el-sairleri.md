# Kəklik

Canım kəklik gözüm kəklik
Yerişin yarıma bənzər
Dönüb dönüb qıya qıya
Baxışın yarıma bənzər

Varıb dağa dayananda
Eşq odına bu yananda
Səhər-səhər oyananda
Gülüşün yarıma bənzər

Qayalardan gəlir ünün
Çəmənlərdə keçir günün
Əginində var sincab donun
Geyişin yarıma bənzər

Üzü ki çəkməmisən dağa
Görmədim yüzündən ağa
Siyəh zülfi tər buxağa
Salışın yarıma bənzər

Əmir aydır xəlq xuyun
Ağ yüzünə düşmüş muyun
İşin köçək rəng ruyun
Oxuşun yarıma bənzər
