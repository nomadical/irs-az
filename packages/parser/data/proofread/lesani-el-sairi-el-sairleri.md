# Xəbər ver

Badi-səba, apar mənim peyğamım,
Başın üçün o dildara xəbər ver.
Yalvar, yapış, ağla, sızla yavunca,
Ərzi-halım sitəmkara xəbər ver.

Çərxi-fələk xub durubdur qəsdimə,
Müşküldəyəm, əlin yetər dəstimə,
Qəm ləşkəri hücum eylər üstümə,
Alişandır o sərdara xəbər ver.

Ləsani tək cismim düşdü bağına,
Rəhmin gəlsin sinəm üstə dağına,
Yetişincə öp əlin, düş ayağına,
Al başına vara-vara xəbər ver.
