# Açıldı

Əqlim başdan getdi, xiyalım çaşdı,
Giriban çak oldu, bellər açıldı,
Sərasər aləmi qıldı müəttər,
Dağıldı gisular, tellər açıldı

Aşiqəm, ey nəsli-pərizad,
Sənə hicr əlindən dad eylərəm dad,
Bu viranə könlümü eylədin abad,
Nitqə gəlib şirin dillər açıldı

Dərdin canda, ey mah, olubdur əyan,
Əqlim zail etdin, ciyərim biryan,
Ahu qədin üzrə töküldü həryan,
Pürpiç olan şuka güllər açıldı

Səni sevdim, düşdüm dərdi-hicrana,
Həsrətindən bağrım dönübdür qanə,
Yenə şeyda bülbül düşdü əfğanə,
Yaz oldu, sünbüllər güllər açıldı

Giriftarəm onun göz və qaşına,
Mehnəti-hicran ilə oldum aşinə,
Qərq edib aləmi aldı başına,
Şeydayi çeşmindən sellər açıldı
