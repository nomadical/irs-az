# Həsənin

Yarə deyin bizdən qarğış almasın,
Yerdə qalmaz ah-zarı Həsənin,
Gecə gündüz həsrətini çəkməkdən
Qalmayıbdır canı yarı Həsənin

Könül əldən qoymaz gül yüzlü yarı,
Sübh və şam küyünə eylər güzarı,
Deyib danışmağa gəlmir heç varı,
Üzülübdür ixtiyarı Həsənin

Bağça sənin, bağban sənin, bar sənin,
Alma sənin, heyva sənin, nar sənin,
Aləm bilir, yar sənin, dəryar sənin,
Canı başı gül vari Həsənin
