# Gəraylı: Gəl ey bülbül, bahar keçdi

Gəl ey bülbül, bahar keçdi,
Nə ağlarsan, nə sızlarsan,
Mövsümi-laləzar keçdi,
Nə ağlarsan, nə sızlarsan

Məskənindir gül bu dağı,
Güzət gül açılan çağı,
Yeri gəz dost gəzən bağı,
Nə ağlarsan, nə sızlarsan

Gəl suyu səp bu gülzara,
Haqq etsin dərdimə çarə,
Can ver vəfalı dildara,
Nə ağlarsan, nə sızlarsan

Usan bir nalə çəkməkdən,
Səhər göz yaşı tökməkdən,
Bivəfaya can verməkdən,
Nə ağlarsan, nə sızlarsan

Boy verməz eşqin dəryası,
Sərdən getməz yar sevdası,
Müznibin din-ü-dünyası,
Nə ağlarsan, nə sızlarsan
