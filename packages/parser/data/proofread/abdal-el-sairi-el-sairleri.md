# Mürəbbə: Bahar fəsli yaz ayları gələndə

Bahar fəsli yaz ayları gələndə
Oxur bizim yerin qazalağları
Narınc turunc hayva ilə nar ilə
Dolar təmam gülli qora bağları

Kəndimizdə bağça bostan əkərlər
Nərlərə yükləyib şəhrə tökərlər
Seçmək üçün müştərilər çökərlər
İri olur tərxun reyhan bağları

Bizim yerin yaxşı olur işləri
Bişirərlər dadlı şilan aşları
Marağa dökisi ağ lavaşları
Dadlı qaymaqları kərə yağları

Aşıq Abdal alsa əlinə sazları
Dolar çevrəsinə Gəncə qızları
Çəkdi Səlminin ala gözləri
Əmrahın köksünə yaxşı dağları
