# Deyir

Kim gələrsə bu cahana lütfi-yəzdanam deyir,
Pəhləvanam yer yüzündə əhli-colanam deyir

Zal-u-Rüstəm tab qılmaz, sovyah kimdir qəhrəman,
Rüz-i-meydani-cəng cuyəm, şiri-dövranam deyir

İrtikabi ləhv-ü-ləbə, mərifətdən bixəbər,
Çirki-dünya cəm qılmış mir-ü-sultanam deyir

Kizb ilə qeybət dilində zay eylər məzhəbin,
Sövm yox qılmaz səlatı, mən müsəlmanam deyir

Bəz hüsni-zən içində laf urub eylər cəfa,
Nan bilər, mənanı bilməz, bəhri-ürfanam deyir

Kəndi nəfsi üçün oxudur, geyinir salus tək,
İlminə qılmaz əməl, alim-ü-insanam deyir

Rəğbəti şübhə-həramə, rüşvəti pünhan dutar,
Satıban dinin dinara əhli-imanam deyir

Nəqd ömrin əkl-ü-şürbə, xəft-ü-xizə sərf edir,
Ruz-u-şəb dərgahi-haqqda bəndeyi-fərmanam deyir

Bu Məlali xaki-payi-fəqr-ü-qəm viranəsi,
İntizari-dari-üqba bunda mehmanam deyir
