# Var

Ol gündən lənət olsun şeytana,
Ondan ötrü çoxlu fitnə-feli var,
Mən də xəcil oldum ol vəqtdən bəri,
Ol səbəbdən böyük-kiçik yolu var

Lənət olsun kor şeytanın gözünə,
Ol zaman ki qərrələnür özünə,
Hər kimsə ki baxar onun sözünə,
Nə işinin sağı, nə də solu var

İncitdim, əzizim, mən o gün səni,
Günahım əfv elə, məzur tut məni,
Beynində çox olur cahilin qanı,
Guyaki əlində İran eli var

Baxıban şad olur dost-u-düşmanlar,
Sənə qurban olsun nazənin canlar,
Bir tərəf olubdur çox xanimanlar,
Özü şeyda bülbül, qönçə gülü var

Peşimanlıq əl verdi, göndərdim qasid,
Yaman bəlalara tuş olsun həsid,

# Xəbər ver

Badi-səba apar mənim peyğamım,
Başın üçün o dildara xəbər ver,
Yalvar, yapış, ağlasızla yavunçı,
Ərzi-halım sitəmkara xəbər ver

Nisan təki çeşmim döndü yağına,
Rəhmin gəlsin sinəm üstə dağına,
Yetcək öp əlin, düş ayağına,
Aliyişanə o sərdara xəbər ver

Dərdi-qəm əlindən çəkirəm aman,
Yetiş fəryadıma, ya Sahibəzzaman,
İqbal sərnigun, bəxtdir yaman,
Məni munda günü qara xəbər ver

Müştaqiyəm, ömrüm getdi talana,
Qarışmışam məni dərdə salana,
İllər ilə sənə həsrət qalana,
Gözü yolda intizara xəbər ver
