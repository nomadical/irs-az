# Gəraylı: Ala gözlü nazlı yardan

Ala gözlü nazlı yardan
Mən dönərəm, könül dönməz,
Çeşmi cadu fitnəkardan
Mən dönərəm, könül dönməz

Sovuq sular gəlir dağdan,
Gül bənövşə qoxur bağdan,
Gümüş qəbqəb ağ buxaqdan
Mən dönərəm, könül dönməz

Nə görmüşəm dəxi eldən,
Can mürğünə verməz xaldən,
Ləbi şəkər, dili baldan
Mən dönərəm, könül dönməz

Nə umarsan zülfi mardan,
Qurtulmadım ah və zardan,
Bu bimürvət zalım yardan
Mən dönərəm, könül dönməz

Bu şikəstə düşdü dildən,
Qucmaq istər nazik beldən,
Yanaqları qızıl güldən
Mən dönərəm, könül dönməz
