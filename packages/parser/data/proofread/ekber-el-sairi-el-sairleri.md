# Yandırdın Məni

Yanasan yanasan yandırdın məni
Sən də mənim tək yanasan könül
Kafirsən rəhmin yoxmuş zalım
Yanasan yanasan yandırdın məni

Əğyarlar sözümü qələt qandırmış
Arada rəqib var o inandırmış
Mənim ah-naləm dağı yandırmış
Yanasan yanasan yandırdın məni

Heç kimsə xublara mayil olmasın
Onların andına qail olmasın
Heç kimin ağası cahil olmasın
Yanasan yanasan yandırdın məni

Əkbərəm olmuşam dəli divanə
Məskənim olubdur belə viranə
Yanaram şəmə nicə pərvanə
Yanasan yanasan yandırdın məni
