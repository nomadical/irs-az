# Neylim

Bahar oldu, qurı çaylar daşalı,
Sökuldu könlümün bəndi, neylim.
Xubların sərdarına könlüm düşəli,
Ciyər kabab oldu, yandı, neylim.

Baxın indi şol bülbülün zarına,
Aşiq oldur kim sarıla yarına,
Gətirmədi əhd-iqrarı yerinə,
Dilbər iqrarından döndü, neylim.

Mömin qulun cənnət olur məzarı,
Dostun dosta kimyadır nəzəri,
Yarım yadlar ilən qurmuş bazarı,
Gəlmiş mənə içər andı, neylim.

(Katibi) aydır: sil könlünün pasını,
Arayıb bul gözlərin xasını,
Doldurmuş əlində zəhr tasını,
Susu deyib ağu sundu, neylim.
