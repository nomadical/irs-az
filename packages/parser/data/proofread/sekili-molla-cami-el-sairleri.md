# Barama

Ustalar, qulaq verin, tərif edim baramanı,
İbtida sərtu çıxmırhi dökürəm baramanı,
Altından qamçı salıb qaldırıram baramanı,
Çatmayadək qalxmağa yoxdur onun heç amanı,
Nə deyim, bu sözümün yoxdu xilafi, yalanı

Çox məşəqqətlə keçirib maqaradan bağladım,
Yaxşı işləsin deyibən maqaranı yağladım,
Asta asta basıban çərxin həvasın saxladım,
Heç dolanmadı, qırıldı, axırı zar ağladım,
Nə deyim, bu sözümün yoxdu xilafi, yalanı

Çün qırıntı ilə doldurdı çərxin qolunu,
Sahib mal gəlibən göstərdi ona yolunu,
Ustanın beli sınır təpədə bilməz qolunu,
Nə deyim, heç görməmişdim yənginlərin çölünü,
İnanın bu sözümün yoxdu xilafi, yalanı

Növbəti bu zülmlə mən elədim təmam kamal,
Pəndir ipək yeməyə heç yoxdur məndə məcal,
Çün düşürüb bağlaram görünər o misli qəcal,
