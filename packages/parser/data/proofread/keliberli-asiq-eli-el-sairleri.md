# Olmuşam

Nə saatda gəldim dünya evinə,
Şum sitarə bəxti bağlu olmuşam.
Taleyim bəd, günüm qara, cəfakeş,
Hicran evli dərd otaqlu olmuşam.

Fələk qoymadı ki bircə yarıyım,
Gözüm açdım, gördüm özüm qarıyım,
Dərd ü möhnət, hicran, qəm sərdarıyım,
Bu dünyada dərd sıxnaqlu olmuşam.

Əliyəm çox çəkdim dərd ü bəladən,
Qəm əl götürmədi mən mübtəladən,
Aləmi-ərvahda qalu bəladən,
Xun-cigərlu qara dağlu olmuşam.
