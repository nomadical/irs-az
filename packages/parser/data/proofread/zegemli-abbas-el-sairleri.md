# Qalmasın

Aləmləri babət-babət yaradan
Nə qaldı ki qul başına gəlməsin
Asılıban nazlı yarın telindən
Düşüb ölsəm heç kəs qanım almasın

Fələk imiş bu işləri qayıran
Ac gözümü torpaq ilən doyuran
Məni səndən, səni məndən ayıran
Heç illərlə üzü-gözü gülməsin

Biçarə Abbasam qaldım qəzadə
Aşiqlərin canı çıxdı cəfadə
Pərvərdigar bəlkə edə iradə
Heç qisasdar qiyamətə qalmasın
