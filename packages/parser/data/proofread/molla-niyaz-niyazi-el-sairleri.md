# Pəltək adamın dilindən

Şə-şə-şə şəha cəmalın kə-kə-kə kəmal olubdur,
Lə-lə-lə ləbin şərabı zu-zu-zu zülal olubdur

Tə-tə-tə təbarəkallah cə-cə-cə cəmalın, ey mah,
Gü-gü-gü gün ilə aya mə-mə-mə misal olubdur

Bə-bə-bə bəlayi-hicrin ə-ə-ə-əsirim mən,
Xə-xə-xə xəyali-vüsalın mə-mə-mə məhal olubdur

Gö-gö-gö gözün hərami o-o-o olalı, ey can,
Sə-sə-sənə bu qanım hə-hə-hə halal olubdur

Ni-ni-ni Niyazi halın sə-sə-sə sevər qəmər kim,
Qə-qə-qə qəmin yeməkdən hə-hə-hə hilal olubdur
